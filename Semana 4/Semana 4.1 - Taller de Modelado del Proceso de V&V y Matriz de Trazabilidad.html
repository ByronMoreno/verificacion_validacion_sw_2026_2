Taller 4.1: Modelado del Proceso de V&V y Matriz de Trazabilidad (RTM)

En este laboratorio diseñarás el ciclo formal de Verificación y Validación para tu Proyecto Integrador alineado con ISO/IEC/IEEE 29119-2, construirás la Matriz de Trazabilidad de Requisitos (RTM) con correspondencia bidireccional entre historias de usuario, componentes de código y casos de prueba, y ejecutarás un protocolo guiado de Walkthrough técnico entre pares.

🎯 Competencias a Demostrar
  • ✅ Modelar el Flujo de V&V: Estructurar las compuertas de calidad (Quality Gates) desde requisitos hasta el cierre de pruebas.
  • ✅ Construir la Matriz RTM: Vincular de forma unívoca requisitos funcionales y no funcionales con sus casos de prueba asociados.
  • ✅ Simulación de Walkthrough: Documentar un acta de revisión técnica entre pares con registro formal de hallazgos.
🔄 Actividad 1: Modelado de las Compuertas de Calidad (Quality Gates)

Define las 4 compuertas de calidad que debe superar un incremento de software antes de llegar a producción:

[ REQUISITOS ] ──( Gate 1: Inspección Estática de User Stories )──> [ DISEÑO ARQUITECTÓNICO ] ──( Gate 2: Revisión Técnica C4 y Contratos API )──> [ CÓDIGO FUENTE ] ──( Gate 3: Linter + SonarQube + Tests Unitarios Coverage > 80% )──> [ INTEGRACIÓN & CI/CD ] ──( Gate 4: Pruebas de Integración + Criterios de Cierre )──> [ DEPLOY ]
🔗 Actividad 2: Estructuración de la Matriz RTM del Proyecto Integrador

Diligencia la matriz de trazabilidad con al menos 6 requisitos clave de tu proyecto (4 funcionales y 2 atributos ISO 25010):

ID Requisito Descripción / Criterio Gherkin Componente Técnico ID Prueba Tipo de Prueba Criterio de Aceptación
RF-01 Registro de usuarios con validación de correo institucional UserRegistrationController / MailValidator TC-REG-01 Caja Negra / Equivalencia Rechaza correos sin dominio @unibe.edu.ec con HTTP 400.
RF-02 Cálculo de aranceles y descuentos por beca académica BecaCalculationService.ts TC-BECA-01 Caja Blanca / Decisiones Aplica el 30% exacto para GPA ≥ 9.0 sin errores de redondeo.
RNF-01 Latencia de consulta de notas bajo carga (Eficiencia) GradesQueryAPI / RedisCache TC-PERF-01 Rendimiento (JMeter) P95 < 250 ms con 150 estudiantes concurrentes.
RNF-02 Cifrado de datos sensibles en reposo (Seguridad) Database / AES-256 GCM TC-SEC-01 Auditoría Estática Contraseñas con hash Argon2id; campos médicos cifrados en BD.
👥 Actividad 3: Protocolo y Acta de Walkthrough Técnico

Los equipos intercambiarán su especificación de requisitos con otro equipo y ejecutarán un recorrido guiado de 30 minutos registrando las observaciones en el siguiente formato:

ACTA DE REVISIÓN WALKTHROUGH TÉCNICO (ISO 29119-3) ----------------------------------------------------------------- Proyecto Evaluado: Sistema de Gestión Académica Artefacto Inspeccionado: Especificación de Casos de Uso v0.1 Autor del Artefacto: [Nombre del estudiante autor] Revisores: [Nombres de los 2 compañeros evaluadores] Fecha y Duración: 2026-10-18 · 30 minutos REGISTRO DE OBSERVACIONES: 1. [Hallazgo 1]: RF-03 omite la acción del sistema ante desconexión de red en el paso 4. (Severidad: Media). 2. [Hallazgo 2]: No se define el umbral de reintentos para la autenticación biométrica. (Severidad: Alta). 3. [Acuerdo]: El autor actualizará la especificación en la rama 'feature/rf03-fixes' antes de la Semana 5.
📊 Rúbrica de Evaluación (10.0 Puntos)
Criterio Excelente (100%) Aceptable (70%) Deficiente (0-40%) Puntos
Modelado de Quality Gates Compuertas de calidad claras, secuenciales y con criterios de pase medibles en CI/CD. Flujo básico con criterios de aprobación informales. Sin compuertas ni criterios definidos. 3.0 pts
Matriz RTM Bidireccional Trazabilidad completa para al menos 6 requisitos con IDs unívocos, componentes y pruebas. Matriz incompleta o sin vinculación directa a componentes técnicos. Matriz vacía o con requisitos sin probar. 4.0 pts
Acta de Walkthrough Registro riguroso de hallazgos técnicos clasificados por severidad y con acuerdos de retrabajo. Acta con comentarios genéricos sin clasificación de severidad. Sin evidencia de revisión entre pares. 3.0 pts
